# GetNotes 📝

GetNotes is a personal web-based notes application for everyday notes, daily records, and simple financial tracking.

This project is built as a learning project to understand how a modern web application works from the ground up.

## 🎯 Project Goals

GetNotes will eventually support:

- Create, read, update, and delete notes
- Daily notes and records
- Note categories
- Search notes
- Favorites
- Daily financial tracking
- Income and expense records
- Simple financial summaries

## 🛠️ Technologies
